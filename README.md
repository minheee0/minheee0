### 안녕하세요, 박민희입니다 👋

**쓰는 사람의 문제에서 출발해, 실패하는 경우까지 책임지는 개발자**가 되고 싶습니다.
화면부터 서버, DB, 결제, 배포까지 기능 하나를 끝까지 맡아서 만드는 일을 좋아합니다.

- 💳 요즘은 예약·결제처럼 돈과 데이터가 걸린 서버를 주로 만듭니다. 동시에 들어온 요청, 중간에 끊긴 결제 같은 경우를 어떻게 처리할지 고민하는 게 재미있습니다.
- 🔁 끝난 프로젝트도 다시 열어 봅니다. 팀 분석 결론을 다시 검증하다 결론이 뒤집힌 적도 있고, 대회가 끝난 뒤 보안 문제를 찾아 고친 적도 있습니다.
- 🤖 Claude Code로 새 기술을 빠르게 익히고, 결제·동시성처럼 틀리면 안 되는 부분은 직접 정하고 테스트로 확인합니다.
